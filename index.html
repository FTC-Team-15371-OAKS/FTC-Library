How it works

GitHub does the heavy lifting.

No account on this site. No custom upload server. Submissions use the tools teams already have.

01

Describe the resource

Use the submission form to collect the team, season, category, license, attribution, and links.

02

Open a GitHub issue

The form prepares a prefilled issue. Attach files or paste links, then submit it to the library repository.

03

Get reviewed and published

A maintainer checks attribution and licensing. Approved resources are added to the JSON library and appear here.
